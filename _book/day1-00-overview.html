1  Day 1 — Overview

Today you build a machine learning model that works, and then you break it. Both halves matter. A model that works is a morning’s work and most of you will manage it before the first break. Knowing the conditions under which it stops working is the part that distinguishes a health data scientist from someone who can call .fit().

The thread running through the day is a single clinical question:

Given a patient’s age and illness severity on admission, how long will they stay in hospital?

We will answer it, measure how well we answered it, and then find out what happens when the hospital changes.

1.1 Objectives

By the end of the day you should be able to, without looking anything up:

  • Write the same data-wrangling, model-fitting and plotting step in both R and Python, and say which parts of your result are language-dependent.
  • Name the five steps of a supervised learning pipeline and say what each one is protecting you against.
  • Fit a regression model, evaluate it on held-out data, and compare it against a baseline that does no learning at all.
  • Explain why a test-set score is not a promise about next year’s patients.
  • Distinguish a change in who the patients are from a change in how the outcome arises, using evidence rather than assertion, and say which of the two your model can survive.

Do them in order. Exercise 1.3 depends on the model built in Exercise 1.2 — it rebuilds it in its first cell, but the argument only makes sense if you have already fitted and evaluated it yourself.

1.3 What you need before you start

  • A browser. Nothing else: the code cells run in the page. If your connection is slow, open Chapter 2 and press Run on the first cell before the session starts, so the runtime is cached.
  • Module 2 linear regression: what a coefficient is, and what a residual is. You do not need anything about p-values today — we will not compute one.
NoteA note on what we are not doing today

We treat length of stay as a pure prediction problem: we want a number that is close to the truth, and we do not ask whether age causes longer stays. That restraint is doing real work. A model can predict well using a variable that would be useless, or harmful, to intervene on. Causal questions arrive later in the module; today, prediction only.
