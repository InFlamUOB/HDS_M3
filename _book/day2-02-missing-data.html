5  Exercise 2.3 — Missing data

5.1 Objectives

  • Describe the missingness in a file numerically and visually, and say how many rows are complete without counting them by hand.
  • Decide whether a missingness pattern is plausible as something a clinic produced, using a comparison rather than an impression.
  • Impute missing values with a stated rule, and name two properties of the data your imputation changed.

5.2 Why this, here

In Chapter 4 the absent values were disguised as zeros. Here they are honest NAs, which removes the detective work and leaves the harder question: once you can see the holes, what do you do about them? Describing the pattern comes first, because the pattern decides whether filling the holes is reasonable at all.

5.3 A second file, and two warnings about it

data/longisland_heart.csv holds 200 patients and 14 columns of cardiac assessment. Two things about it must be said before anything else.

  • The outcome, diagnosis of heart disease, has five levels, not two. It is a severity grade. Nothing today models it, and anyone who reaches for a two-class method on Day 4 should come back and check this first.
  • The clinical variables are not in clinical units. trestbps — resting blood pressure — runs from 1 to 41, and chol from 1 to 100. Somebody recoded or binned these columns and did not write down how. You cannot say whether an imputed chol of 29 is plausible, because you do not know what 29 means.

That second point is not a flaw in the exercise. It is the ordinary state of a teaching extract, and recognising it is part of the work.

Counts per column do not tell you whether the gaps line up. Three views, each answering a different question.

5.5 Task 1 — Decide whether a clinic could have produced this

Look again at the column counts you printed above, then build the comparison that settles it. Simulate a frame in which 20 values are knocked out of each of 13 columns completely at random, count how many rows end up incomplete, and repeat that a few hundred times. Compare the real file against that distribution.

Each column needs 20 missing out of 200, so each simulated column is a shuffle of 20 TRUEs and 180 FALSEs. A row is incomplete if it has at least one.

5.6 The result that should bother you

The simulation matches. The real file has 150 incomplete rows and random knockout produces around 150 as well, comfortably inside the simulated range. So the row-level pattern is consistent with missing completely at random — and that is the finding, because no clinic produces missingness completely at random.

  1. Every one of the 13 predictors has exactly 20 missing values. Not 19, not 22. A process that loses values independently in thirteen different columns does not land on the same count thirteen times; the probability of that is vanishing. Somebody wrote a loop.
  2. Compare with Chapter 4, where every missing triceps was also a missing insulin. That nesting is what a real process looks like: tests are ordered in bundles, bundles are skipped together, and the patients they are skipped for are not a random sample.
  3. So this file is an exercise in mechanics, not in diagnosis. Imputation methods are safe to practise on it precisely because the missingness is artificial and ignorable. Do not take that reassurance with you.

The useful habit is the one you just performed: when a pattern looks regular, simulate the process you think produced it and check whether the data lies inside the result.

5.7 Task 2 — Impute, and measure what you changed

Fill the numeric gaps with the column median, then compare the standard deviation and a correlation before and after. Median rather than mean, because these columns are recoded and skewed; the argument for it is the same either way.

The function that returns the middle value of a vector, with na.rm = TRUE so that it can be computed at all. ifelse() is doing the replacing; you supply the number it replaces with.

# Replace every ______ below, then run this cell.
from sklearn.impute import SimpleImputer

imputer = SimpleImputer(strategy="______")

Single-value imputation moves 20 patients to the exact centre of the distribution. The standard deviation falls, every one of those patients is now claimed to be perfectly average, and the next analysis has no way of telling which rows were invented. The mean survives; almost nothing else does.

NoteWhat mice adds

mice (multivariate imputation by chained equations) fills each gap by predicting it from the other columns, and does the whole thing several times so that downstream estimates can carry the uncertainty. One complete frame from it is still a guess, but it is a guess that respects the relationships between columns rather than flattening them.

library(mice)
imp <- mice(heart, m = 5, printFlag = FALSE, seed = 1)
chol_imp <- complete(imp, 1)$chol
c(observed_sd = sd(heart$chol, na.rm = TRUE),
  median_imputed_sd = sd(heart_imp$chol),
  mice_sd = sd(chol_imp))
#>       observed_sd median_imputed_sd           mice_sd 
#>          29.90516          28.44966          29.68802

Use the version of this you can defend. On a file with 10% missing and a single-value imputation, say so in the methods; on anything important, use multiple imputation and say that.

5.8 Task 3 — Categorical columns, and the order that matters

sex and cp (chest pain type) are categories stored as numbers. Models need them as indicator columns, and the encoder has to be given data without gaps — otherwise “missing” silently becomes a category of its own.

Build a ColumnTransformer that imputes and then encodes, and check how many columns come out. In the R version, exclude = c(NA, NaN) earns its place: this file’s gaps arrive as NaN rather than NA, and factor() would otherwise give them a level called “NaN” and report nothing missing at all.

Now do it in the wrong order — encode first, impute afterwards — and look at the column names. The encoder, handed a column containing NA, treats “missing” as a value worth a column of its own, and you have added a predictor that says this patient’s chest pain type was not recorded. Sometimes that is exactly what you want and you should say so out loud. What you must not do is create it by accident.

The two languages fail differently, and the R failure is the safer one. step_dummy() propagates the missing value into every indicator column, so the gaps are still gaps and the next step still has to deal with them — and if you then add step_impute_mode(), recipes refuses outright, because the columns it is being asked to fill are numeric now. scikit-learn produces sex_nan and cp_nan: no missing values, no warning, and two extra predictors nobody asked for.

5.9 Reflection

  1. You imputed chol with its median without knowing what the units are. Name one thing that could be wrong with the imputed values that you would be unable to detect.
  2. Multiple imputation gives five different filled-in datasets. If the five disagree about an answer you care about, what does that disagreement tell you, and what would you report?

5.10 Stretch

NoteStretch 1 — Is missingness informative here?

Add a column chol_missing and test whether it is associated with the outcome grade. In this file it should not be, by construction. Run the same test on insulin_missing in data/diabetes.csv and compare. One of these files is teaching you mechanics and the other is teaching you suspicion.

NoteStretch 2 — Pool, do not pick

Fit the same simple model on each of the five mice completions and look at how much the coefficient for one predictor moves between them. That spread is the part single imputation throws away. pool() is the function that combines them properly.

5.11 What you can and cannot now claim

Can: that you can describe a missingness pattern in numbers and in a picture, that you tested a hypothesis about how it arose rather than asserting one, and that you can impute and state what the imputation cost.

Cannot: that any of this was done safely. Every statistic you used to fill a gap — a median, a mode, a mice model — was computed from the whole file, including the rows you will later use to test a model. That is Chapter 7, and it is the reason today is built this way.
