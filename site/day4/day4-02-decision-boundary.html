Exercise 4.2 — The decision boundary

In Exercise 4.1 the map of the logistic regression’s probability had a black line across it: to one side the model says yes, to the other no. That line is the decision boundary. In this exercise you work it out from the coefficients, see why it is straight, and move it with the threshold.

We use the same people as Exercise 4.1: age, systolic blood pressure, and whether they had a cardiovascular event in the next ten years. Both measurements matter, so the boundary is tilted.

  • Part 1. Find the boundary by hand from the coefficients, draw it, and see it in 3D as the line where the S-shaped probability sheet cuts the plane P = 0.5.
  • Part 2. Change the threshold and see the line move: every threshold gives its own line.

Part 1 — Where the class changes

Fit a logistic regression with both measurements, the same way as in Exercise 4.1:

log_model <- logistic_reg() |>
  set_engine("glm") |>
  set_mode("classification")

log_fit <- log_model |>
  fit(cvd ~ age + systolic_bp, data = train)

b <- log_fit$fit$coefficients      # intercept, age, blood pressure
b
#>  (Intercept)          age  systolic_bp 
#> -13.82914222   0.10193471   0.05082533

The model is a straight line on the log-odds scale. Log-odds are another way of writing a probability \(p\): \(\log\big(p / (1 - p)\big)\). A probability of 0.5 has log-odds 0; higher probabilities have positive log-odds, lower ones negative. The sigmoid turns log-odds back into a probability.

\[\text{log-odds} = \beta_0 + \beta_1 \times \text{age} + \beta_2 \times \text{blood pressure}\]

By default the model says yes when the probability is 0.5 or more. At 0.5 the probability is shared equally between the two classes: 0.5 for an event and 0.5 for no event. Above it yes is the more likely class, below it no. So the class changes where the probability is 0.5, which is log-odds of 0. So the boundary is every combination of age and blood pressure where

\[\beta_0 + \beta_1 \times \text{age} + \beta_2 \times \text{blood pressure} = 0\]

For a given blood pressure, solve for age:

\[\text{age} = \frac{-\beta_0 - \beta_2 \times \text{blood pressure}}{\beta_1}\]

The same line in three dimensions

The model turns age and blood pressure into a probability with the sigmoid. Drawn above the age–blood pressure floor, that probability is an S-shaped sheet between 0 and 1. The flat grey plane is the level P = 0.5. The decision boundary, the black line, is nothing more than where the sheet cuts through that plane: where the sheet is above the plane the model says yes, where it is below, no. Seen from above, it is the line you drew in Task 1a. Turn the plot with the mouse and scroll to zoom.

Code for this plot (optional) 
# This plot needs the plotly package: install.packages("plotly")
ages <- seq(40, 80, by = 1)
bps  <- seq(80, 200, by = 2)

# the probability at every grid point (one row per blood pressure, one column
# per age): the sigmoid of the log-odds
logodds_matrix <- outer(bps, ages, function(s, a) b[1] + b[2] * a + b[3] * s)
prob_matrix <- 1 / (1 + exp(-logodds_matrix))

# the boundary: the age where the probability is 0.5 (log-odds 0), for each blood pressure
line_age <- (-b[1] - b[3] * bps) / b[2]
on_floor <- line_age >= 40 & line_age <= 80

plotly::plot_ly() |>
  plotly::add_surface(x = ages, y = bps, z = prob_matrix, opacity = 0.75,
                      colorscale = list(c(0, 1), c("steelblue", "darkorange")),
                      showscale = FALSE, name = "probability") |>
  plotly::add_surface(x = ages, y = bps, z = 0 * prob_matrix + 0.5, opacity = 0.4,
                      colorscale = list(c(0, 1), c("grey", "grey")), showscale = FALSE,
                      name = "P = 0.5") |>
  plotly::add_trace(type = "scatter3d", mode = "lines", x = line_age[on_floor],
                    y = bps[on_floor], z = rep(0.5, sum(on_floor)),
                    line = list(color = "black", width = 8), name = "boundary at 0.5") |>

Part 2 — Other thresholds, other lines

The cut-off of 0.5 is called the decision threshold. Nothing forces it to be 0.5: we could call someone yes from a probability of 0.3, or only from 0.7. Each threshold gives its own line. Each line is where the S-shaped sheet of Part 1 is cut by a flat plane at that height: the plane at 0.3 sits lower and cuts the sheet at younger ages and lower blood pressures; the plane at 0.7 sits higher and cuts it further up. Seen from above, the three lines are parallel: the same tilt, shifted.

Code for this plot (optional) 
lines_t <- data.frame(t = factor(c(0.3, 0.5, 0.7)),
                      log_odds = log(c(0.3, 0.5, 0.7) / (1 - c(0.3, 0.5, 0.7)))) |>
  mutate(intercept = (log_odds - b[1]) / b[3], slope = -b[2] / b[3])

ggplot(test, aes(x = age, y = systolic_bp)) +
  geom_point(aes(shape = cvd), size = 2, colour = "grey30") +
  geom_abline(data = lines_t, aes(intercept = intercept, slope = slope, colour = t),
              linewidth = 1) +
  scale_shape_manual(values = c(no = 1, yes = 17)) +
  scale_colour_manual(values = c("0.3" = "blue", "0.5" = "red", "0.7" = "purple")) +
  coord_cartesian(xlim = c(40, 80), ylim = c(80, 200)) +
  labs(x = "Age (years)", y = "Systolic blood pressure (mmHg)",
       shape = "Event", colour = "Threshold",
       title = "Three thresholds, three parallel boundaries")
ImportantKey idea

We could have picked another threshold, and we would have had a different line separating our classes in 2D: one line for each threshold. The 0.5 line, where both classes are equally likely, is only the default.

Everyone above a line is predicted yes at that threshold. Count them:

test_probs <- predict(log_fit, new_data = test, type = "prob")$.pred_yes

c(t_0.3 = sum(test_probs >= 0.3), t_0.5 = sum(test_probs >= 0.5),
  t_0.7 = sum(test_probs >= 0.7))
#> t_0.3 t_0.5 t_0.7 
#>    50    34    17
ImportantThink about it

Lowering the threshold from 0.5 to 0.3 calls many more test patients yes. On the plot, which patients change side when the line moves from 0.5 to 0.3: triangles (they had an event), circles (they did not), or both?

ImportantLearning points
  • The decision boundary is where the predicted probability equals the threshold: where the S-shaped sheet cuts a flat plane at that height. At 0.5 the two classes are equally likely, and the log-odds are 0.
  • A logistic regression’s boundary is straight (flat) in its predictors. Another threshold gives another, parallel line: the same tilt, shifted.

Part 2 — Other thresholds, other lines

The cut-off of 0.5 is called the decision threshold. Nothing forces it to be 0.5: we could call someone yes from a probability of 0.3, or only from 0.7. Each threshold gives its own line. Each line is where the S-shaped sheet of Part 1 is cut by a flat plane at that height: the plane at 0.3 sits lower and cuts the sheet at younger ages and lower blood pressures; the plane at 0.7 sits higher and cuts it further up. Seen from above, the three lines are parallel: the same tilt, shifted.

ImportantKey idea

We could have picked another threshold, and we would have had a different line separating our classes in 2D: one line for each threshold. The 0.5 line, where both classes are equally likely, is only the default.

Everyone above a line is predicted yes at that threshold. Count them:

test_probs = log_model.predict_proba(test[["age", "systolic_bp"]])[:, 1]

print("t = 0.3:", (test_probs >= 0.3).sum())
#> t = 0.3: 40
print("t = 0.5:", (test_probs >= 0.5).sum())
#> t = 0.5: 27
print("t = 0.7:", (test_probs >= 0.7).sum())
#> t = 0.7: 14
ImportantThink about it

Lowering the threshold from 0.5 to 0.3 calls many more test patients yes. On the plot, which patients change side when the line moves from 0.5 to 0.3: triangles (they had an event), circles (they did not), or both?

ImportantLearning points
  • The decision boundary is where the predicted probability equals the threshold: where the S-shaped sheet cuts a flat plane at that height. At 0.5 the two classes are equally likely, and the log-odds are 0.
  • A logistic regression’s boundary is straight (flat) in its predictors. Another threshold gives another, parallel line: the same tilt, shifted.
